# economy-simulator

### DESCRIPTION
A simple economy simulation that will involve buying and selling goods with supply and demand impacting goods prices, with a visual to demonstrate the price, demand, and supply of goods.

### IMPORTANT DETAILS
VERSION 1: Just includes random buying and selling of one good with a fixed price and only 5 merchants.
VERSION 1.1: Will include better merchant decision-making, reactive pricing, more merchants

### BUILD INFORMATION
Run the main.py file.

### TECHNICAL DETAILS
Price is determined by # of potential buyers based on how many can buy without going below their threshold, supply determined simply by how much of the item there is.
